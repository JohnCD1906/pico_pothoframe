# Pico Photo Frame

Proyecto con RP2040 que muestra imágenes BMP desde una microSD en una pantalla ST7789.

## Features
- Slideshow automático
- Transiciones (fade, slide)
- Lectura de BMP 24-bit desde SD (FatFS)
- SPI doble: pantalla + SD

## Hardware
- Raspberry Pi Pico (RP2040)
- Pantalla ST7789 240x240
- Módulo microSD (HW-125)

## Uso
Colocar imágenes BMP 240x240 en:
/photos
